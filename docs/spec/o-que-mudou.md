# O que mudou

Palavras de versões anteriores que não existem no GoiásScript 3. Elas não são reservadas; só melhoram a mensagem de erro (GS0306).

| Aposentada | Forma na v3 | Observação |
|---|---|---|
| `presta_serviço` | `faz_trem` | função se declara com faz_trem |
| `vai_na_frente_presta_serviço` | `vai_na_frente_faz_trem` | função assíncrona se declara com vai_na_frente_faz_trem |
| `mexe_assim` | sem equivalente | método de classe não leva palavra; o construtor é aprepara_trem |
| `vixe_que` | `vixe` | vixe recebe a mensagem direto |
| `vazio` | `nada` | valor ausente é nada |
| `sei_lá` | `indefinido` | valor não definido é indefinido |
| `se` | `se_ocê_quiser` | condicional é se_ocê_quiser |
| `senao` | `se_não` | senão é se_não |
| `fazer` | `faz_trem` | função é faz_trem |
| `é_igual_a` | `é_igualim` | igualdade é é_igualim |
| `um_tanto_de` | sem equivalente | saiu da linguagem, sem substituto na v3 |
| `ninguem_fuça` | sem equivalente | saiu da linguagem, sem substituto na v3 |
| `só_da_famia` | sem equivalente | saiu da linguagem, sem substituto na v3 |
| `todo_mundo_vê` | sem equivalente | saiu da linguagem, sem substituto na v3 |

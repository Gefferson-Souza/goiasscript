# RFC-0001, anexo F: formulário para falantes de Goiás

Respostas de 2 a 3 pessoas criadas em Goiás. O parecer é consultivo; a decisão é do dono. Registrar no anexo F só
o primeiro nome ou um apelido e a cidade.

**Instruções para quem responde.** Para cada frase, diga se você fala desse jeito no dia a dia. Se fala diferente,
escreva como você falaria. Não pense em programação; pense numa prosa com alguém de casa.

| # | Situação | Frase | Você fala assim? (sim / às vezes / não) | Como você falaria? |
|---|---|---|---|---|
| 1 | Pedir para alguém esperar um pouco | "Espera um cadim." | | |
| 2 | Avisar que algo vai acontecer logo | "Daqui um cadim eu faço." | | |
| 3 | O momento exato de agora | "Agorinha mesmo." | | |
| 4 | Desistir de algo que estava combinado | "Larga mão disso." | | |
| 5 | Quando uma coisa dá certo | "Quando der bão, cê me avisa." | | |
| 6 | Esperar todo mundo terminar | "Espera tudim junto." | | |
| 7 | Tirar uma coisa de um lugar | "Ranca isso daí." | | |
| 8 | Procurar uma coisa no meio de outras | "Cata aí pra mim." | | |
| 9 | Juntar várias coisas numa só | "Ajunta tudo." | | |
| 10 | Um pedaço de alguma coisa | "Me dá um naco." | | |
| 11 | Perguntar a quantidade | "Qual o tanto que tem?" | | |
| 12 | Pôr as coisas em ordem | "Arruma isso aí." | | |
| 13 | Dizer que é tudo, sem faltar nada | "Todin ali." | | |
| 14 | Pedir para alguém mostrar um erro | "Reclama aí." | | |
| 15 | Algo deu errado | "Deu ruim." | | |

**Pergunta aberta.** Tem alguma palavra ou jeito de falar bem goiano que você acha que devia aparecer numa linguagem
de programação feita em goianês?

# Primeiro programa com prosa

Todo programa começa com uma prosa. A palavra `prosa` bota na tela o que ocê mandar
dentro dos parênteses, sô. O texto vai entre aspas.

```goiasscript exemplo
prosa("Bão, sô!")
```

Mexe no texto aí em cima e roda de novo. Cada `prosa` escreve uma linha nova:

```goiasscript
prosa("Primeira linha")
prosa("Segunda linha")
```

Agora é com ocê: faz o programa dizer `Olá, Goiás!` no exercício.
